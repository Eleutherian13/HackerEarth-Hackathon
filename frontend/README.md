# Frontend

This folder contains the user interface for reviewing judgments and compliance plans.

Quickstart:
- Development: see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#frontend)
- Install deps: `npm install` or `yarn` in `frontend/`
- Run locally: `npm start` (or `yarn start`)

Build:
- Create production build with `npm run build`.

Testing:
- Frontend tests are in `frontend/tests/` — run with the chosen test runner (see `package.json`).

- User guide: [docs/USER_GUIDE.md](docs/USER_GUIDE.md)
- Architecture: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
