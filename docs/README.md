# Documentation

This folder contains the product, architecture, deployment, and user-facing documentation for the system.

## Contents

- `API.md` documents service endpoints and payloads.
- `ARCHITECTURE.md` captures the system design.
- `DEPLOYMENT.md` explains deployment and environment setup.
- `USER_GUIDE.md` explains how operators and reviewers use the system.
- `ADR/` contains architecture decision records for major technical choices.
- `MISSION.md` captures the system mission and operating constraints.
